Agent Reach
76.2k stars · MIT License
Give your AI agent eyes to read the entire internet. Search Twitter, Reddit, YouTube, GitHub, Bilibili, XiaoHongShu — one CLI, zero API fees.
Use When
Researching competitors or trends on social media
Reading YouTube tutorials or extracting subtitles
Searching Reddit for bug solutions or opinions
Checking GitHub repos, issues, and discussions
Monitoring RSS feeds for updates

Graphify
Knowledge Graph · Zero API Cost
Turn any codebase, docs, or papers into a queryable knowledge graph. Understand architecture, trace dependencies, and find hidden connections.
Use When
Understanding a new codebase's architecture
Tracing how Module A connects to Module B
Reviewing documentation alongside code
Finding god nodes, bottlenecks, and hidden deps
Keeping architecture docs auto-updated
# Build a knowledge graph of your project: graphify . # full pipeline graphify query "How does auth work?" # ask questions graphify path "Auth" "DB" # trace relationships
Best at Debug + Build
🛡️
Strix
58.9k stars · Apache 2.0
AI penetration testing — autonomous agents that find and fix your app's vulnerabilities. Real exploit validation, not false positives.
Use When
Security audit before shipping to production
Finding OWASP Top 10 vulnerabilities automatically
Testing API endpoints for auth bypass or injection
CI/CD security scanning on pull requests
Generating compliance-ready pentest reports
# Install and run first scan: curl -sSL https://strix.ai/install | bash strix --target ./app-directory
