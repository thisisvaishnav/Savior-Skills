# Web Research

## Workflow

1. **Define the question.** Break broad topics into specific, answerable sub-questions before searching.
2. **Search strategically.**
   - Use precise queries with quotes, site filters, and date ranges.
   - Try multiple phrasings; never rely on a single search engine result.
3. **Evaluate sources.** Prefer primary sources, official documentation, peer-reviewed papers, and reputable institutions. Check publication dates and author credentials.
4. **Cross-check claims.** Any important claim should be confirmed by at least two independent sources. If sources conflict, note the disagreement explicitly.
5. **Synthesize and cite.** Summarize findings in your own words, always linking back to the original source URL.

## Rules

- Never present a single unverified source as fact.
- Record the full URL and access date for every citation.
- Distinguish clearly between facts, expert opinion, and speculation.
- If information cannot be verified, say so rather than filling gaps with assumptions.
